# Ala-Too Supermarket

Mobile-first supermarket storefront prototype built with React and TypeScript.

## Features
- Product catalogue, category filters, and search
- Shopping cart with quantity controls
- Delivery and in-store pickup checkout
- Manual MBANK transfer flow with a placeholder QR and payment reference

## Run locally

```bash
npm install
npm run dev
```

This is a frontend demo only. Prices and products are sample data; the QR is a placeholder; orders are not saved to a backend and no payments are processed. Never send real money through this prototype.
